# Wiki Operating Manual

This page is the human-readable companion to `AGENTS.md`. The canonical schema
and workflow rules live in `AGENTS.md`.

## Operating Principle

This wiki compounds by integration. A source ingest should update the source
summary, topics, concepts, claims, comparisons, contradictions, open questions,
synthesis, index, and log where useful.

## Task Types

- setup
- ingest
- query
- lint
- maintenance
- experiment-result-ingest
- synthesis-update
- refactor-wiki
- research-gap-analysis
- output-generation
- schema-update
- source-classification

## Standard Preflight

Before edits, read `AGENTS.md`, `index.md`, and recent `log.md` entries. Then
identify relevant pages and summarize the planned changes.

## Standard Closeout

After edits, update `index.md`, append `log.md`, cross-link pages, mark
uncertainty, show changed files, point to the useful `git diff`, and recommend a
commit message.
